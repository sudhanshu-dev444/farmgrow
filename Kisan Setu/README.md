# Kisan Setu (किसान सेतु) 🌾

Kisan Setu is a digital agriculture and rural connectivity platform empowering farmers with seamless mandi token generation, slot booking, payment tracking, quality check lifecycle management, and direct market linkage.

---

## 📁 Repository Structure

- **[`kisan_setu_app/`](./kisan_setu_app)**: Complete Flutter-based cross-platform application (Web & Mobile).
- **[`web_app/`](./web_app)**: Standalone web application with integrated interface and simulation controls.
- **[`stitch_kisan_rural_connect/`](./stitch_kisan_rural_connect)**: UI screens, design tokens, and modular view prototypes.

---

## 🚀 Getting Started

### 1. Running the Flutter App
```bash
cd kisan_setu_app
flutter pub get
flutter run -d chrome
```

### 2. Running the Web App
Open [`web_app/index.html`](./web_app/index.html) directly in any modern browser or host it via a local static server:
```bash
cd web_app
# Using python
python -m http.server 8000
# or npx serve
npx serve .
```
